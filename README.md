# МУ Подготовка — Биология и Химия

Локално приложение за подготовка за кандидатстудентския изпит по **Биология за МУ** и **Химия** (МУ-Варна).
Без инсталация, без акаунт: отвори `index.html` в браузър. Целият прогрес се пази автоматично в `localStorage`.

## Режими

| Режим | Какво прави |
|---|---|
| **Теми** | Обяснение, ключови факти, диаграми, термини, капани и въпроси с незабавни обяснения |
| **Назови термина** | Показва определение — пишеш точния термин. Мигновена проверка (приема малки правописни грешки с по-малко XP), подсказки, пропуснатите отиват в „Грешките ми“ |
| **Бърз огън** | 20 въпроса × 15 s, комбо множители ×1.5 / ×2 / ×3, бонус за скорост, рекорд |
| **Тест на случаен принцип** | Пробен изпит (10–50 въпроса, по един или двата предмета) с таймер и оценка по шестобалната система |
| **Шефът на блока** | 20 въпроса от блока за 25 min; победа при 5.50+. Лента „овладяване“ за всеки блок |
| **Отворени въпроси** | Пишеш пълен отговор → Claude го оценява като строг изпитващ спрямо ключа: %, оценка, пропусната терминология, грешки, съвети |
| **Грешките ми** | Повторение с интервали (1 → 3 → 7 дни) за въпроси, термини и отворени въпроси |

Прогресия: XP, медицински рангове (Санитар → Медицински брат/сестра → Кандидат-студент → Студент → Стажант → Ординатор → Доктор → Специалист → Доцент → Професор), дневна цел и серия от дни с 14-дневен календар.

## AI оценяване

В **Настройки** постави своя Anthropic API ключ (от console.anthropic.com). Той се пази само в `localStorage`
на браузъра и се изпраща единствено до `api.anthropic.com` (директна заявка от браузъра). Моделът по подразбиране е
Claude Opus 5.5; може да се смени на Sonnet 5.5 или Haiku 4.5 за по-ниска цена. Без ключ можеш да сравниш отговора си с ключа ръчно.

## Файлове

- `index.html` — входна точка
- `css/styles.css` — стилове (светла и тъмна тема)
- `js/app.js` — цялата логика
- `js/data-biology.js`, `js/data-chemistry.js` — базите с теми, въпроси, термини и ключове (взети от изходните материали)
- `js/data-custom.js` — **тук добавяш свои термини, отворени въпроси, въпроси с избор и нови теми** (напр. за Блок II и III по химия)

Експорт/импорт на прогреса (JSON) — от Настройки.
