# 🐼 МедПанда — Биология и Химия за МУ

Игра за подготовка за кандидатстудентския изпит по **Биология за МУ** и **Химия**, вдъхновена от езиковите приложения с ежедневна серия.
Без инсталация, без акаунт: отвори `index.html` в браузър. Прогресът се пази автоматично в `localStorage`.
Талисманът Д-р Панда (панда с лекарска престилка) реагира на всичко, което правиш.

## Учебният цикъл

**Учи → упражнявай → повтаряй грешките → пази серията → гледай прогреса.**

- **Път на обучение** за всеки предмет: блокове → теми като възли (🔒 заключена · ⚪ незапочната · 🟡 в процес · 🟢 овладяна) и 👑 шеф в края на всеки блок.
- **Урок** по тема, стъпка по стъпка:
  1. 📖 Научи — обяснение, схема, ключови факти, капани
  2. ✏️ Упражнение — въпроси с избор
  3. 🎯 Назови термина — пишеш термина по определение
  4. 🔥 Предизвикателство — по-трудни въпроси
  5. 🤖 AI отворен въпрос (по желание)
  6. 🎉 Резултати — XP, точност, серия, овладяване „преди → след“, нови постижения
- Грешен отговор → обяснение и същият въпрос отново в края на урока.

## Режими

| | |
|---|---|
| 🏠 Начало | Днешна цел (XP), серия, ранг, препоръчан урок, бързи действия |
| ❤️ Грешките ми | Повторение след 1 → 3 → 7 дни, слаби теми, „опитай пак“ |
| 🔥 Бърз огън | Комбо ×1.5 / ×2 / ×3, времето намалява, трудността расте |
| 🎯 Назови термина | Мигновена проверка, приема малки правописни грешки |
| 🤖 AI отворени въпроси | Claude оценява като строг изпитващ от МУ спрямо ключа |
| 👑 Шефът на блока | 20 въпроса / 25 min, победа при 5.50+ |
| 🎲 Тест на случаен принцип | Пробен изпит с оценка по шестобалната система |
| 🏆 Профил | Ранг, ниво, статистики, постижения, овладяване, история |

Рангове: Санитар → Медицински кандидат → Студент → Старши студент → Стажант → Лекар → Доктор → Специализант → Медицински експерт.

## AI оценяване

В ⚙️ Настройки постави своя Anthropic API ключ. Той се пази само в `localStorage` и се изпраща единствено до
`api.anthropic.com`. Модел по подразбиране: Claude Opus 5.5 (може Sonnet 5.5 или Haiku 4.5 за по-ниска цена).

## Файлове

- `index.html` — входна точка
- `css/styles.css` — визуална система (светла и тъмна тема, без анимации при `prefers-reduced-motion`)
- `js/panda.js` — талисманът (SVG с 8 изражения и медицински аксесоари)
- `js/app.js` — цялата логика
- `js/data-biology.js`, `js/data-chemistry.js` — съдържанието от изходните материали
- `js/data-custom.js` — **тук добавяш свои термини, въпроси, отворени въпроси и цели теми** (напр. Блок II и III по химия)
