# 🐼 МедПанда — Биология и Химия за МУ

Игра за подготовка за кандидатстудентския изпит по **Биология за МУ** и **Химия**: път на обучение, уроци стъпка по стъпка,
серия от дни, XP, рангове, постижения, „Бърз огън“, „Назови термина“, „Шефът на блока“, тестове и „Грешките ми“.
Талисманът Д-р Панда реагира на всичко, което правиш. Прогресът се пази автоматично в `localStorage` на браузъра.

Отворените въпроси се оценяват от **Claude чрез твоя Claude абонамент (Pro/Max)** — през официалния
[Claude Agent SDK](https://code.claude.com/docs/en/agent-sdk/overview), работещ в малък локален сървър на твоя компютър.
Ако Claude не е достъпен, приложението оценява **локално** по официалния ключ и го отбелязва ясно.

---

## 1. Инсталиране (еднократно)

Нужен е **Node.js 18+** (препоръчително 20 или 22).

```bash
npm install
```

Това инсталира `@anthropic-ai/claude-agent-sdk`, който съдържа и самия Claude Code — не е нужна отделна инсталация.

## 2. Вход с Claude Pro абонамента (еднократно)

```bash
npm run claude:login
```

Командата стартира **непроменения Claude Code** (`claude auth login --claudeai`). Отваря се официалната страница за вход на
Anthropic в браузъра; влизаш със своя Claude акаунт. Входът се пази от Claude Code на компютъра ти (системния keychain или
`~/.claude/`) — **не** в този проект, **не** в браузъра и **не** в `localStorage`.

Други команди:

```bash
npm run claude:status   # дали има вход
npm run claude:logout   # изход
```

> Ако в терминала, от който пускаш сървъра, е зададена променлива `ANTHROPIC_API_KEY`, Claude Code ще използва нея
> (платено API) вместо абонамента. Махни я (`unset ANTHROPIC_API_KEY`), ако искаш да използваш само Pro абонамента.
> Статусът в Настройки показва кой начин се използва.

## 3. Стартиране

```bash
npm run dev
```

Отвори **http://localhost:5178**. (Друг порт: `PORT=6000 npm run dev`.)

Без сървъра можеш да отвориш и `index.html` директно — всичко работи, но отворените въпроси се оценяват само локално.

## 4. Проверка дали Claude е свързан

**⚙️ Настройки → 🤖 Claude AI**:

| Статус | Значение |
|---|---|
| 🟢 Свързан · Claude абонамент | Има вход и последната заявка е успешна |
| 🟠 Има вход, но последната проверка е неуспешна | Напр. изчерпан лимит или няма интернет — виж съобщението |
| 🔴 Не е свързан | Изпълни `npm run claude:login` |
| ⚪ Локалният сървър не работи | Стартирай `npm run dev` |

Бутонът **„Провери връзката“** прави една минимална реална заявка към Claude. **„Свържи Claude“** показва стъпките за вход.

## 5. Как работи AI оценяването

```
Браузър ──POST /api/grade──► локален сървър (127.0.0.1) ──► Claude Agent SDK ──► твоят Claude акаунт
   ▲                                                                                   │
   └──────────────── валидиран JSON с оценката ◄──────────────────────────────────────┘
```

Сървърът изпраща на Claude: въпроса, официалния ключ (рубриката), задължителните термини от темата (само тези, които са в ключа),
отговора на ученика и максималния резултат. Claude действа като **строг изпитващ от МУ**:

- оценява реалното съдържание, не само ключовите думи; не дава точки за неясни твърдения;
- посочва липсващи понятия, грешни твърдения и липсваща терминология;
- не наказва дребни правописни грешки, ако смисълът е верен;
- **никога** не добавя изисквания извън подадения ключ.

Claude няма достъп до инструменти (`tools: []`), до файловете на проекта или до твоите настройки на Claude Code
(`settingSources: []`), и сесиите не се записват (`persistSession: false`).

Отговорът се **валидира** на сървъра (тип и граници на резултата, списъци от текст, дължини). Пропуснати термини, които
не присъстват в официалния ключ, се изхвърлят. Пример:

```json
{
  "score": 82, "xpPercent": 82, "passed": true,
  "feedback": ["Правилно описваш основната функция на митохондриите.", "Липсва терминът „окислително фосфорилиране“."],
  "missedTerms": ["окислително фосфорилиране"],
  "correctConcepts": ["синтез на ATP"],
  "missedConcepts": ["роля на дихателната верига"],
  "incorrectConcepts": [],
  "gradingMode": "claude"
}
```

Резултатът се отразява навсякъде в играта:

- **XP** = резултат% × 50 (максимумът за отворен въпрос); при повторен опит — само за подобрението;
- дневна цел и серия, ниво и ранг, овладяване на темата и блока, статистика;
- под 60% → въпросът отива в **„Грешките ми“**; пропуснатите термини от темата също се добавят там за преговор;
- постиженията „Пред комисията“ и „Чиста шестица“ се отключват **само** от оценка на Claude.

## 6. Локално оценяване (резервен вариант)

Ако Claude не е достъпен (няма вход, изчерпан лимит, няма интернет, сървърът не работи или приложението е отворено като файл),
оценяването се прави от `js/grader-local.js` — на сървъра или директно в браузъра. То сравнява отговора с всеки елемент от
официалния ключ (с толеранс за българските окончания) и дава пълен, половин или нулев дял за елемент.

Резултатът е отбелязан с **„🧮 Локално оценяване“** и причината. **То не е равностойно на Claude**: не разбира смисъла и не
открива грешни твърдения — отговор с фактическа грешка, но с правилните думи, може да получи висок локален резултат.

## 7. Къде е кодът

| Файл | Какво прави |
|---|---|
| `server/index.mjs` | Локален HTTP сървър: сервира приложението и `/api/*`; слуша само на `127.0.0.1` |
| `server/claude.mjs` | Claude Agent SDK: статус, „Провери връзката“, оценяване, образцов отговор |
| `server/grading.mjs` | Промпт на изпитващия, JSON схема, валидиране на входа и изхода |
| `server/claude-cli.mjs` | `npm run claude:login/status/logout` чрез вградения Claude Code (само `auth`) |
| `server/test/` | Тестове (`npm test`) |
| `js/grader-local.js` | Локалното оценяване (общо за браузъра и сървъра) |
| `js/app.js` | Цялото приложение (UI, игри, прогрес) |
| `js/data-*.js` | Съдържанието по биология и химия; `data-custom.js` — твоите допълнения |

**Сигурност на сървъра:** слуша само на localhost; приема `/api` заявки само от самото приложение (проверка на `Host`, `Origin`,
`Sec-Fetch-Site` и собствена заглавка `X-MedPanda`); ограничава размера на заявките; сервира само `index.html`, `css/` и `js/`;
не логва текстове на отговори, ключове или токени; не връща към браузъра никакви данни за вход.

## 8. Какво НИКОГА не се качва в GitHub

`.gitignore` вече ги изключва, но провери преди всеки commit:

- `node_modules/`
- `.env`, `.env.*` и всякакви файлове с ключове (`*.pem`, `*.key`, `credentials.json`, `.credentials.json`)
- папката `~/.claude/` и всичко от нея (там Claude Code пази входа) — тя е извън проекта; не я копирай в него
- `.claude/` в проекта, `*.local.json`
- експортираните файлове с прогрес (`medpanda-progress-*.json`), ако не искаш да ги споделяш

## Важно: условия за използване на абонамента

Според [документацията на Anthropic](https://code.claude.com/docs/en/legal-and-compliance#authentication-and-credential-use)
вход с Claude Pro/Max е предназначен за **обичайна, лична употреба** на Claude Code и Agent SDK. Това приложение е за един човек
на собствения му компютър: входът става през официалния поток на Anthropic в непроменения Claude Code и приложението никога не
вижда, не пази и не пренасочва данните за вход. Anthropic **не позволява** да се предлага вход с Claude.ai на други хора чрез
собствено приложение или да се пренасочват заявки на други потребители през твоя абонамент. Ако някога решиш да споделиш
приложението като услуга за други хора, премини към API ключ от [Claude Console](https://platform.claude.com/) — всеки
потребител със собствен ключ.
